프로젝트 소개

FastAPI와 JavaScript를 활용하여 하노이의 탑 알고리즘을 시각적으로 표현함 원판의 이동 과정을 애니메이션으로 확인하며 재귀 함수의 동작 원리를 눈으로 쉽게 이해 가능함

사용 기술

Python · FastAPI

웹 서버를 구성 및 웹페이지 생성

HTML

입력창 / 버튼 / 기둥 등 화면의 구조를 구성

CSS

배경 / 원판 / 기둥의 디자인과 화면 배치를 담당

JavaScript

이동 순서 계산 / 애니메이션 / 속도 조절 기능을 처리

알고리즘 설명

최소 이동 횟수 = 2n - 1

주요 기능

  • 원판 개수 설정 및 자동 크기 조절
  • 원판 이동 애니메이션과 속도 조절
  • 일시정지 및 재개
  • 초기화 및 진행 과정 표시
